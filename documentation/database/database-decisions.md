# قرارات قاعدة البيانات ومبرراتها

| القرار | المبرر |
|---|---|
| `domain` فريد عالمياً | يمنع توجيه الدومين إلى موقعين ويطابق سياسة المشروع. |
| `websites` جذر المستأجر | يحتوي `id` فقط؛ لا يضاف إليه `website_id`. الجداول المالكة تستخدم `website_id` ومفاتيح مركبة عند الحاجة. |
| العلاقات المركبة | تستخدم `(website_id,parent_id)` مع `(website_id,id)` في الجدول الأب، بينما العلاقات المباشرة تستخدم `website_id -> websites.id`. |
| إزالة `www` قبل التخزين | يجعل تمثيلي `www.example.com` و`example.com` متساويين. |
| دومين أساسي واحد كحد أقصى | `primary_website_id` generated column مع `UNIQUE(primary_website_id)`؛ NULL للدومينات غير الأساسية. القيد يمنع التعدد ولا يفرض الوجود. |
| دومين أساسي قبل التفعيل | `WebsiteService` يتحقق من وجود دومين أساسي قبل تفعيل الموقع، وينفذ إنشاء الموقع وتعيين الدومين والتفعيل داخل Database Transaction. يمنع حذف أو إلغاء تعيين الدومين الأساسي إذا ترك ذلك موقعاً مفعلاً بلا دومين أساسي. |
| `UNIQUE(website_id,slug)` | يسمح بنفس المسار في مواقع مستقلة ويمنع تعارضه داخل الموقع. |
| القالب النشط في `websites` | مصدر واحد للحالة النشطة دون آلية منافسة. |
| إعدادات القالب في جدول مستقل | يحفظ تاريخ القوالب ويدعم التراجع دون لمس المحتوى. |
| إعداد قالب نشط واحد | `active_template_id` generated column مع `UNIQUE(website_id,active_template_id)`؛ السجلات المحذوفة منطقياً تاريخية. |
| JSON للمحتوى المرن فقط | يحافظ على مرونة الأقسام دون إخفاء العلاقات العلائقية. |
| تحقق Service لمراجع JSON | MySQL لا يفرض FK داخل JSON؛ التحقق يثبت ملكية media. |
| media مملوك لكل موقع | يمنع مشاركة ملفات خاصة بين المواقع. |
| إعدادات الموقع Key/Value | جدول موحد بـ`setting_key` و`setting_value JSON` دون أعمدة branding مكررة. |
| لا `admin_users` | المصادقة المركزية مطلوبة عبر متغيرات البيئة فقط. |
| أرشفة بدلاً من الحذف التلقائي | تمنع فقد المحتوى وكسر الروابط والمراجع. |
| MySQL/InnoDB/utf8mb4 | توافق صريح مع الخطة وPDO وDocker. |
| Migrations صريحة | تمنع تغييرات schema غير قابلة للتتبع أثناء HTTP. |

## نقاط تحتاج تطبيقاً في المراحل اللاحقة

تطبيع والتحقق من الدومين والـ slug، فحص دورات navigation، التحقق من JSON ومراجع media، نسخ default-media، والمصادقة كلها مسؤوليات التطبيق/Service حيث لا يكفي قيد MySQL وحده. أما تفرد الدومين الأساسي وتفرد إعداد القالب النشط فمفروضان بقيد generated column في MySQL. لا تنشئ هذه الوثيقة آلية تنفيذها.
